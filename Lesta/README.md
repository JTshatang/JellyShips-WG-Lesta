# 莱斯塔-保持Q弹

莱斯塔《Мир кораблей》的Windows客户端视觉Mod。舰船随节拍循环压扁、变宽、拉高和收窄，船长保持原值。可预览并调整船形，也可单独开关船尾航迹。

## 安装流程

1. 从 GitHub Releases 下载压缩包并解压。退出游戏（尽量连游戏启动器也退出），将整个“莱斯塔-保持Q弹”文件夹拖入莱服 Mod 目录。一般位于`游戏根目录\bin\最大的数字（即客户端最新版本）\res_mods`。
2. 双击文件夹中的“莱斯塔-保持Q弹.exe”。工具自动注册舰船资源，安装完毕后进入设置窗口。

### 方案与船形

内置“邦友的酒”和“朋友的酒（DJ版）”两个方案。切换方案会同时切换歌曲和船形。可在“方案管理”改名，在“效果预览”调宽高，再点“保存方案”。退出游戏后点“应用到游戏”，下次启动就会使用这个方案。“恢复默认动画”会恢复默认曲线和两端宽高。

宽高滑块为1%–200%。数字框可填更大的百分比，超出预览框的部分会裁切。再次拖动滑块时，数字框会采用滑块指到的值。

点“动画曲线…”，在“简易编辑”中把“最高”向左拖，舰船会更早弹高。把“最扁”向右拖，船会在起弹前停一下。也可以输入拍位百分比。点“播放”可看完整动作，或拖时间轴看某一刻的舰艏。有歌时可勾选“配乐”。在“自定义曲线”中选一个点，可将高亮的一段切换为“平滑曲线”或“直线”。多峰和旧速度曲线可原样回看，点“套用简单动作”可换成默认动作。点“撤销”退回上一步，按Esc可取消正在进行的拖动。

旧自定义方案保留歌曲、名称和船形，可用“速度曲线…”编辑一拍内的快慢。选择“转为船高曲线”后可以直接拖动圆点，转换后的曲线可能略有变化。

退出游戏后，勾选“启动保持Q弹”并点“应用到游戏”可启用，取消勾选后应用可暂时停用。取消勾选“显示航迹效果”并应用，舰艉后方的白色尾流会隐藏。

### 歌曲与试听

在“效果预览”点“试听”可听当前方案的歌曲。拖动进度会更新船形，点“暂停”可定格，再点“试听”会接着播。试听音量可独立调节，选“循环预览”可回到无声动画。试听无需应用方案或启动游戏。循环歌曲之间可以留白，留白期间仍会显示船形动画。

在“方案管理”点“新建方案”，可用“动画 BPM”设置无歌速度，默认130，可填1–600和小数。可以无声预览、保存或应用。使用无歌方案时，舰船按设定速度Q弹，Mod音乐和播放快捷键保持静音。

自建方案可点“添加歌曲…”“换歌…”，也可拖入本地WAV、MP3、M4A、FLAC，或内含MP3或FLAC的网易云NCM。歌曲最长60分钟。工具自动估算BPM和鼓点，估拍把握较低时会提示有些段落可能错拍，未取得拍点时按130 BPM循环。选中试听进度条后，可用方向键每次微调10毫秒。两个内置方案始终绑定各自原曲。

“移除歌曲”会保留方案和船形，恢复上次手调的BPM，首次可沿用歌曲的BPM。“删除方案”会移除整个自建方案。导入的音频和拍点保留在启动器旁的`玩家数据\Songs`。退出游戏并点“应用到游戏”后，歌曲和方案才会切换到游戏里。

### 战斗配乐

到“音乐设置”点“启用本次游戏音乐”。可以先开工具再开游戏，等候时可以取消。启用后可以关闭设置窗口。回港会停歌，同一次游戏的下一场仍可用，退出游戏后音乐助手自动结束。

战斗音乐默认在成功进入战斗时自动播放，并循环播放当前歌曲。两首内置歌曲的参考速度均为130 BPM，原速播放。每拍最扁处对齐鼓点。港口和回放保持静音，离场时淡出。晚进入视野的其他舰船可能与本舰错拍。

点“暂停／恢复”可暂停音乐，再点一次会等本舰回到相应拍位，从断点继续。“重头播放”会重新对拍，从曲首开始。离场会清除暂停位置。可拖动音量滑条或输入0%–100%，对已应用方案即时生效，0%时音乐仍继续计时。

点“暂停／恢复”或“重头播放”旁的键位，看到“请按键”后，按F8之类的单键或Ctrl+Shift+K之类的组合。可以取消录入以保留原键，也可清除为“未设置”。退出游戏后点“应用到游戏”。快捷键在已取得本舰拍点、游戏位于前台的战斗中生效。

### 更新、迁移和卸载

正式发布版打开设置时会自动检查GitHub Releases。发现适配当前游戏构建的新修订时，工具在游戏目录内下载并校验，待退出游戏和关闭设置后安装。若游戏仍在运行，下次打开时会继续处理。离线时仍可使用当前版本。

游戏升级后，可打开仍在的旧构建入口获取匹配新构建的正式包，也可直接把新包放进新构建目录。若担心游戏中心先清理旧目录，在“程序维护”点“导出方案和歌曲”。将导出ZIP中的“玩家数据”文件夹放入新包的品牌文件夹，再首次打开，即可恢复。

首次迁移到绿色版时，按上面的安装流程操作。发现旧版备份或上一游戏构建中的玩家数据时，可选择复制方案和歌曲。旧版的固定启动器可在“程序维护”清理。若安装提示发现手动装过的旧Mod，请先退出游戏，将提示中的旧文件夹移出游戏目录备份。要导入旧设置，在新入口旁创建“旧设置”文件夹，放入备份的`Beat.seq`，也可放入`settings.txt`、`effects.txt`和`music\preferences.json`（保留`music`子目录），然后打开新入口。安装完成后可将“旧设置”移回备份位置。若旧版安装记录缺少文件清单，工具会将旧Mod文件备份到`res_mods`下的`.JellyShips-legacy-…`目录。

退出游戏后，可在“程序维护”选择“卸载保持Q弹…”。默认保留方案和歌曲。取消“保留我的方案和歌曲”再确认会一并删除。

### 已知差异与致谢

目前所有换模皮肤都无法正常显示动画，如克利夫兰皮肤“自由”、西蒙玻利瓦尔皮肤“下水仪式”，以及黑五船只的黑色皮肤。

WG版及动画参考来自B站UP主“电棍Anno”，莱服版经作者同意发布。[WG版效果演示](https://www.bilibili.com/video/BV1NpWB6LESD/)

## 二次开发

`src/launcher`是安装、更新和卸载入口，`src/mod`是舰船注册和默认动画，`src/editor`是设置窗口与舰艏预览，`src/music`是播放器与战斗事件处理。源码下载中的舰船与特效资源共用`assets/game-resources.zip`，构建时直接读取。[构建、资源与发布说明](DEVELOPMENT.md)
